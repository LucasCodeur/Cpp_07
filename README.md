# CPP Module 07

## Overview

**CPP Module 07** introduces **C++ templates** and generic programming.

The module focuses on writing functions and classes that can work with different data types without duplicating their implementation.

## Objectives

* Create function templates.
* Create class templates.
* Work with generic types.
* Understand template instantiation.
* Reuse algorithms with different data types.
* Apply templates to data structures.

## Skills Developed

* **C++**
* Templates
* Generic programming
* Function templates
* Class templates
* Type abstraction
* Code reuse
* Compile-time programming

## What I Learned

This module introduced me to generic programming in C++ and showed how templates can be used to create reusable algorithms and data structures while preserving type safety.
